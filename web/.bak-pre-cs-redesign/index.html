Stale listeners 0

            
Listener records persisted in the Sliver DB with no running job — usually a
              persistent listener that failed to restart at boot (bind IP not up yet, or the port already
              held by another service). They still reserve their port, so re-creating one gives
              "port N is in use" even though nothing is listening. The console
              can't clear these; Remove deletes the stranded DB record.

The beacon sleeps interval seconds between check-ins,
                  randomized by up to jitter seconds. It retries on a dropped C2 every reconnect
                  seconds and gives up after max connection errors failures. Poll timeout caps
                  how long an HTTP long-poll request stays open before the implant reconnects.

Command reference

          
A quick reference for Sliver's built-in console commands, with the
            nearest Cobalt Strike equivalent where one exists. Run these from the
            Sliver tab (or a sliver-client console). Commands
            and flags vary by version — help <command> is always
            authoritative.


          

            
Coming from Cobalt Strike?

            

              
    
                
  • Sessions vs beacons. A session is interactive/real-time; a
                  beacon checks in on an interval (like a CS beacon). List them with
                  sessions / beacons, then
                  use <id> to task one.
    • 
                
  • Beacon tasks are queued. Results arrive on the next check-in — view
                  them with tasks (CS: the pending/received task view).
    • 
                
  • The Armory is your BOF / .NET store.
                  armory install <name> pulls tools like Rubeus, Seatbelt,
                  SharpUp. Run .NET with execute-assembly and BOFs via
                  extensions.
    • 
                
  • Opsec. Prefer execute /
                  execute-assembly / extensions over the noisy interactive
                  shell — same guidance as CS.
    • 
                
  • Sleep. Change a beacon's interval/jitter with
                  reconfig (CS: sleep).
    •
